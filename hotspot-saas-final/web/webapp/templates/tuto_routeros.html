La création automatique des tickets exige RouterOS 7. Si votre routeur est encore en version 6, suivez ce guide. Ne coupez pas le courant pendant la mise à jour, et faites-la de préférence en dehors des heures de vente.
Avant de commencer

Vérifiez votre version actuelle dans System › Packages (colonne Version de la ligne routeros). Si elle commence par 7., vous êtes déjà à jour — rien à faire. Si elle commence par 6., suivez les étapes ci-dessous. Une sauvegarde préalable est conseillée (System › Backup).

1

Ouvrez System › Packages

Dans le menu de gauche, cliquez sur System (1) puis sur Packages (2).

2

Cliquez sur « Check For Updates »

La fenêtre des paquets s'ouvre. À droite, sous Configuration (3), cliquez sur Check For Updates. La ligne routeros vous montre votre version installée.

3

Lancez « Download&Install »

Le routeur compare votre version (Installed Version) à la dernière (Latest Version). Laissez le canal sur stable, puis cliquez sur Download&Install (4).

4

Confirmez par « OK »

Cliquez sur OK (5). Le routeur télécharge la mise à jour puis redémarre tout seul pour l'installer. Ne débranchez rien.

Attendez le redémarrage (2 à 3 minutes)

Reconnectez-vous ensuite avec Winbox. Vérifiez dans System › Packages que la ligne routeros affiche bien une version 7.x. Votre routeur est prêt.

Après la mise à jour, il est recommandé de mettre aussi à jour le firmware de la carte : System › RouterBOARD › Upgrade, puis un dernier redémarrage.
